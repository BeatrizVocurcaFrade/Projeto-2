# Projeto-2: dog gallery (React)

Single-page React app for dog lovers ("Um site para quem ama cachorrinhos!"). Each card fetches a random dog photo from [TheDogAPI](https://thedogapi.com); **Mostrar Mais** ("show more") adds another card, and a spinner shows while each image loads.

**Stack:** React 17 (function components with `useState` / `useEffect`) · Fetch API · CSS per component · Create React App

## Run

```bash
npm install
npm start   # http://localhost:3000
```

Built in 2022 as a React practice project.
